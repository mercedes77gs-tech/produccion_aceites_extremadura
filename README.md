# produccion_aceites_extremadura.
PowerBI sobre los datos de la empresa de produccion de aceite.
Trabajo desde 4 archivos .csv con los datos de centros de coste, lineas de produccion, turnos de trabajo y de la produccion.
Se crea el .pbix realizando la subida de los csv, se limpian en el Query del PowerBI, se realizan calculos, columnas calculadas con nuevas medias, relaciones entre las tablas.
Se busca una imagen que represente a la empresa para lograr un .json corporativo y ,mediante IA se genera el codigo de los colores que representaran todo el Dashboard.
Se crean tarjetas, sliders, graficos, matrices, tablas, segmentacion de datos, varias paginas apoyadas en la de aterrizaje, algunas paginas ocultas para solo mostrar la informacion relevante, 
botones de llamada para vincular paginas y navegar directamente.
Hay dos paginas con informacion sobre los pasos y tips de errores o cambios.
